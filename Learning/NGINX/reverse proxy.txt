proxy: in computer network, a proxy server is a server app that acts as an intermediary b/w a 
       client requesting a resource and server providing that resource

      clint  ------------ proxy ------------- server
  (forward proxy)                          (reverse proxy)


reverse proxy: a service which takes a client request, passes it on to one or more servers
               proxying is used to distribute the load amoung serversl servers, seamlessly show content from diff websites
               or pass requests for processing to app servers over protocols other than HTTP
